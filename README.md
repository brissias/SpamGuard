# Spam Guard
just a simple addon that checks a configurable channel and monitors for repeated messages. it detected it will whisper the player with a configurable message.


> [!IMPORTANT]
> This is for a WOTLK (3.3.5) version of world of warcraft



## Quick start
- /sg channel world  									<SUB>what channel to monitor, Default is set to World*</SUB>
- /sg time 20  												<SUB>time in seconds to use as a trigger, default 30 sec</SUB>
- /sg repeat 2												<SUB>how many repeats of the same message will trigger a whisper, default is set to 3</SUB>
- /sg msg DUDE! CHILL!.. SENT BY SpamGuard.<SUB>what message to send to the infringer</SUB>
