# Spam Guard
just a simple addon that checks a configurable channel and monitors for repeated messages. it detected it will whisper the player with a configurable message.


> [!IMPORTANT]
> This is for a WOTLK (3.3.5) version of world of warcraft



## Quick start

/sg channel world  											-- what channel to monitor, Default is set to World
/sg time 20  												-- time in seconds to use as a trigger, default 30 sec 
/sg repeat 2												-- how many repeats of the same message will trigger a whisper, default is set to 3
/sg msg Alahu akbar! SPAM Detected! Sent by SpamGuard addon -- what message to send to the infringer.
